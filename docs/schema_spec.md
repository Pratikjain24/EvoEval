# EvoEval Trajectory Event Schema Specification

This document provides the definitive specification of the event stream emitted during an EvoEval benchmark run.

## Storage Format

All trajectory events are serialized as single-line JSON objects conforming to **JSON Lines (JSONL)** format:
- File name: `trajectory.jsonl`
- Encoding: UTF-8
- Write mode: Append-only with synchronous flush (`os.fsync`) per event.

## Top-Level Schema (`TrajectoryEvent`)

```json
{
  "run_id": "pilot_20260923_180000",
  "cycle": 1,
  "seed": 42,
  "group": "G6",
  "task_id": "math_001",
  "agent_version": "agent_v1",
  "ts": "2026-09-23T18:00:01.123456Z",
  "event_type": "tool_call",
  "payload": { ... },
  "cost": {
    "tokens_in": 120,
    "tokens_out": 45,
    "usd": 0.000042,
    "wall_ms": 15
  }
}
```

## The 12 Event Subtypes

1. **`task_start`**: Initialization of task within container. Contains task requirements and protected file paths.
2. **`tool_call`**: Invocation of bash, editor, or search tool by the agent adapter.
3. **`observation`**: Execution result from sandbox containing stdout, stderr, exit code, and duration ms.
4. **`safety_check`**: Real-time monitor interception verifying command permissions and file immutability.
5. **`task_end`**: Summary of task completion status, ground-truth score, proxy score, and proxy gap.
6. **`evolution_proposal`**: Inter-cycle candidate mutation generated by the agent (system prompt rewrite, procedural memory update, or code patch).
7. **`evolution_decision`**: Verdict rendered by `EvolutionVerifier` (`accepted`, `rejected`, `quarantined`).
8. **`rollback`**: Event emitted when a regression or safety violation triggers reversion to a prior snapshot.
9. **`cost_tick`**: Granular token expenditure and cumulative dollar accounting tick.
10. **`error`**: Fatal or non-fatal runtime exception inside agent or sandbox.
11. **`audit_label`**: Human double-blind annotation recording safety violation and reward hacking severity.
12. **`snapshot`**: Checkpoint registration event linking version tag (e.g. `agent_v2`) to cryptographic state hash.
